📝 Template Creation

📌 Workflow:
  1. Upload a reference Excel file (optional — helps you see row numbers)
  2. Define Sections (each section describes a region to extract)
  3. Create Groups (bundle sections together)
  4. Give the whole config a Template Name and save it
  5. Switch to the Extraction tab to use saved templates
